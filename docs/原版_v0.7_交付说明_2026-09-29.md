# 原版 v0.7 · 角色与模块调整 · 2026-09-29

产品仅供电脑使用。本轮取消新增的手机适配，以 1440px 和 1280px 桌面浏览器为验收对象。

## 使用方式

双击本目录 `preview.cmd`，或打开 http://127.0.0.1:5173/ 。首先选择管理员或用户／律师身份，点击登录；这是无需密码的演示登录。刷新恢复演示初始状态。

## 导航与功能

| 身份与范围 | 一级导航 |
| --- | --- |
| 管理员，工作区外 | 用户与组（Users、Groups、User Status）、Workspaces、Audit、其他（Task Center） |
| 管理员，工作区内 | 概览、Review Setup（Fields & Layouts、Highlights）、Processing、Documents（Saved Searches、Folders）、Search & Analytics（dtSearch Index、Search Term Report，保留原分析页签）、Redact、Production、其他（Task Center、Review Batches） |
| 用户／律师，工作区外 | 选择工作区 |
| 用户／律师，工作区内 | Documents、Review Batches |

原有客户／事项／工作区创建、权限配置、字段／选项／分类／布局编辑、处理、文档 Viewer、遮盖 QC、制作和任务详情继续复用。文档和批次可以进入原 Viewer 并返回。顶部展示实际选中的工作区，切换后重建当前页面；字段、布局、高亮、Saved Search、批次和 QC 按工作区保存演示状态。

## 演示边界

- 登录按预设身份分流，不包含服务端认证或真实权限校验；律师的工作区授权规则留待后续开发。
- User Status 展示当前账户会话及明确标注的示例在线用户；新建账户显示离线，不冒充真实在线监控。
- Audit 记录本次演示的登录、工作区进出和页面操作反馈，不是完整后台审计系统。
- Search Term Report 在现有示例文档文件名中匹配词语，可进入对应文档结果；不代表真实全文索引。原有全文搜索条件继续保留，未接入检索后端。
- 原有多个工作区复用同一批业务演示资料，新增配置按工作区隔离；本轮不新增真实数据源。
